# FFmpeg Studio

一款基于 FFmpeg 的音视频可视化处理工具。无需记忆命令行，即可完成格式转换、音频/视频处理、截图、GIF 生成、滤镜特效、文件合并、推流拉流、字幕烧录等操作。

## 功能

- **格式转换** — 视频 / 音频 / 图片格式互转，支持自定义编码参数
- **音频处理** — 淡入淡出、音量调节、音频提取
- **截图与 GIF** — 单帧截图、批量截图、视频转 GIF
- **滤镜特效** — 常用滤镜与特效一键应用
- **文件合并** — 视频拼接、图片转视频
- **流媒体** — RTMP 推流、HLS / RTSP 拉流
- **字幕** — 字幕提取与烧录
- **自行命令** — 输入完整 ffmpeg 命令直接执行

## 安装

下载安装包并运行即可，无需额外配置：

- [FFmpeg Studio_0.3.0_x64-setup.exe](FFmpeg%20Studio_0.3.0_x64-setup.exe)

> 安装包已内置 ffmpeg / ffprobe，安装后开箱即用。

## 使用

1. 导入或拖入媒体文件
2. 选择处理方式与输出设置
3. 点击执行，实时查看进度与日志

## 项目结构

```
src/          前端代码（Vue 3 + Element Plus）
src-tauri/    Tauri 桌面端（Rust）
resources/    ffmpeg 运行文件
```

## 环境要求

- Windows 10 / 11 64 位
